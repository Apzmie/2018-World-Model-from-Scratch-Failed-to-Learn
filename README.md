# Under-Construction
World model is a next-state predictor. If an MLP outputs next-state, this MLP is a world model. To predict more accurately, 2018 world model paper suggests a structure: VAE (Variational Autoencoder) + LSTM-MDN (Long Short-Term Memory - Mixture Density Network). VAE converts state into latent representation to extract important features, LSTM-MDN remembers past flow and uses this memory to output a distribution over possible next-states to represent future uncertainty. This structure is optimized by gradients, while the linear controller is optimized by ES (Evolution Strategies) to demonstrate that controller optimization can be done without gradients. After training VAE and LSTM-MDN with a reward predictor, the controller can be trained using the world model without interacting with the real environment because the world model outputs both next-state and reward, just as the real environment does.
